## 4. Desvios conscientes que fiz ao implementar

Já estão nos ADRs 0004 a 0008, mas para você ver tudo num lugar:

- CSS crítico **não** fica embutido no HTML (SPEC-02, RNF-02.1): sai em arquivo separado de cerca de 4 kB gzip.
- A imagem da névoa (07) não é usada: a névoa é só CSS (a spec a deixava opcional).
- O cursor da chave é SVG provisório, não PNG de 48 px.
- A "carta dobrada" que sai do envelope é um retângulo próprio, e a carta real aparece desdobrando (ADR-0007).
- O áudio não segue uma fila de download por ordem de uso; as músicas só baixam metadados até serem tocadas.
- A arte, as fotos e os sons são provisórios ou ausentes; `pnpm verificar` impede a publicação com eles.

4. **Redes sociais (B9):** colocar @isah_nicoly e @_neto085 em algum lugar (por exemplo, no fim das informações)?
5. **"Pra ti eu vou" (B10):** é uma música que o casal quer usar ou era só brincadeira?
6. **"Faltam 1 dia" ou "Falta 1 dia"** (questão em aberto da SPEC-07).
7. **Verso do louvor (B8):** vai entrar? Se não, a mensagem termina em "A sua presença é o nosso maior presente."

   investir na SPEC-15.

Já estão na matriz de testes, mas duas não aparecem em nenhuma spec e merecem atenção: o desbloqueio do `<audio>` das
